# Kalburgi Rotti Kendra – Food Ordering Website

A modern, responsive food ordering web application developed for **Kalburgi Rotti Kendra**, specializing in traditional North Karnataka food.

Built with React.js and Vite, this project provides customers with an intuitive digital ordering experience, featuring a dynamic shopping cart, bilingual interface, GPS-enabled delivery details, and WhatsApp-based order integration.

## Project Overview

The application digitizes the customer's food ordering journey, allowing users to explore products, manage cart items, enter delivery information, and submit orders through WhatsApp.

The system follows a manual order confirmation workflow. The business verifies delivery availability, location, delivery charges, and final order amount before confirming the order.

## Key Features

- **Responsive UI:** Optimized layouts for mobile and laptop screens.
- **Bilingual Interface:** English and Kannada language support.
- **Dynamic Menu:** Product listings with images, pricing, and quantity information.
- **Shopping Cart:** Add, remove, and update product quantities.
- **Checkout System:** Customer details and delivery address collection.
- **GPS Integration:** Capture and share customer delivery coordinates.
- **Google Maps Integration:** Open the shared delivery location in Google Maps.
- **WhatsApp Integration:** Generate and share structured order details through WhatsApp.
- **Next-Day Delivery:** Orders are scheduled for the following day.
- **Payment Preferences:** Cash on Delivery and UPI options.
- **Manual Order Verification:** Delivery charges and order availability are confirmed by the business.

## Installation and Setup

### Prerequisites
- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/8296217152/kalburgi-rotti-kendra-website.git
```

### 2. Navigate to the project directory

```bash
cd kalburgi-rotti-kendra-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Create a production build

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## Order Workflow

1. Customer browses the food catalogue.
2. Customer adds products to the shopping cart.
3. Customer enters contact and delivery information.
4. Customer captures their GPS location.
5. The application generates an order summary.
6. Order details are shared through WhatsApp.
7. Business verifies delivery availability and charges.
8. Final order amount and delivery are confirmed with the customer.
